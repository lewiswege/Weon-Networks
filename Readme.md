# Weon Networks Website

A modern, responsive single-page website for **Weon Networks**, an internet service provider focused on reliable connectivity for homes and businesses.

## Features

- Responsive design for desktop, tablet, and mobile
- Modern blue-themed ISP design
- Internet service plans section
- Coverage information
- Why Weon Networks section
- Contact section with Google Maps
- Customer connection/request form
- WhatsApp integration for connection requests
- Mobile navigation menu
- Favicon and logo support
- Dynamic copyright year
- No backend required

## Technologies

- HTML5
- CSS3
- JavaScript
- Google Maps Embed
- WhatsApp Click-to-Chat
